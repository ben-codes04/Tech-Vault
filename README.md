## About The Project

**Tech-Vault** serves as a structured, accessible web portal designed to organize key technological concepts into clean, easy-to-navigate pages. Built with semantic web standards, it showcases effective document hierarchy, custom styling, and responsive layout practices.

### Built With

* ![GitHub Pages](https://img.shields.io/badge/github%20pages-%23222222.svg?style=for-the-badge&logo=github&logoColor=white)

---

## Features

* **Modular Multi-Page Layout:** Dedicated sections for project context (`about.html`), programming concepts (`languages.html`), and hardware specifications (`parts.html`).
* **Custom Responsive Styling:** Clean layout and adaptability powered by an external stylesheet (`Design.css`).
* **Continuous Deployment:** Hosted directly from GitHub Pages for fast worldwide accessibility.
